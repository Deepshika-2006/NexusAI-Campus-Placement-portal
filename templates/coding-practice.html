Reverse a String

Given a string s, return the string reversed. Do not use a built-in reverse function.

Example Input: "placement" Output: "tnemecalp"
Expected approach

Use two pointers or iterate from the last character to the first. Target complexity: O(n) time and O(n) output space.

Problem 2 of 5 Medium

Two Sum

Given an integer array and a target, return the indices of two numbers whose sum equals the target. Assume exactly one solution.

Example Input: [2,7,11,15], target = 9 Output: [0,1]
Expected approach

Store previously seen values in a hash map. For each value x, check whether target − x has already been seen.

Problem 3 of 5 Easy

Palindrome Check

Return true when a string reads the same forward and backward, ignoring case.

Example Input: "Level" Output: true
Expected approach

Normalize the case, then compare characters from the two ends using two pointers. Target complexity: O(n) time.

Problem 4 of 5 Medium

Second Largest Element

Find the second largest distinct element in an integer array without sorting the entire array.

Example Input: [10, 5, 8, 10, 3] Output: 8
Expected approach

Maintain two variables for largest and second-largest distinct values while scanning once. Target complexity: O(n) time and O(1) extra space.

Problem 5 of 5 Medium

First Non-Repeating Character

Return the first character that appears exactly once. Return -1 if every character repeats.

Example Input: "swiss" Output: "w"
Expected approach

Count frequencies with a hash map, then scan the string again and return the first character with frequency one. O(n) time.
